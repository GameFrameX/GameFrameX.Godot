# 分包加载说明:
- 本模板已经按 Godot 分包插件的新格式接入：主包在 `engine/empty-tips.bin`，分包在 `subpackages/<分包名>/`。
- 游戏内不要再手写 `JavaScriptBridge + ProjectSettings.load_resource_pack`；统一使用 `SubpackRuntime.ensure_subpack_with_dependencies("<分包名>")`。
- `game.json` 里每个 Godot 分包都要有一个同名微信分包，例如 `name: "subpack", root: "subpackages/subpack/"`。
- 微信要求每个分包根目录有 `game.js`，空文件即可；导出整理脚本会自动生成。

# 分包pck加载文件系统优化注意:
- 默认加载pck会保持在内存, 当你有多个pck额外加载的时候注意内存控制及时释放, 下面是是否pck在内存中的占用, 释放不影响功能代码逻辑,只是没有在内存的文件会经历一个加载过程, 自行进行合理分割安排
```gdscript 从内存卸载pck
	var sdk = JavaScriptBridge.get_interface("GODOTSDK")
	var result = sdk.releasePck(current_pck)
	if result:
		print("pck卸载成功")
```

# GLX 兼容性开关
- 默认使用 WeChat GLX。遇到设备黑屏时，将 `glx-config.js` 中的 `GameGlobal.__GODOT_DISABLE_WXGLX` 设为 `true`，启动将固定使用标准 `webgl2`；不要在运行后切换。
