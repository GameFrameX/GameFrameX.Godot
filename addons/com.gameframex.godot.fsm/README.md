## Overview

GameFrameX FSM — Godot generic finite state machine package. Manages creation, lifecycle, and state transitions of typed state machines with per-FSM data dictionaries (Variable). Supports named states, generic data storage across states, FixedUpdate polling, and both generic and named FSM overloads.

## Quick Start

### Installation

Copy the package into your Godot project's `addons/` directory:

```
addons/com.gameframex.godot.fsm/
```

The package is also published to the GameFrameX npm registry, so package-management tooling can consume it directly:

```
https://npm.cnb.cool/GameFrameX/npm/-/packages/
```

### Dependencies

- [`com.gameframex.godot`](https://github.com/GameFrameX/com.gameframex.godot)
