## 简介

GameFrameX UI GdGUI — 基于 Godot 原生 Control 的 GameFrameX UI 框架实现。提供 UIForm 生命周期、打开/关闭管理与层级路由。

## 快速开始

### 安装

将包复制到 Godot 项目的 `addons/` 目录：

```
addons/com.gameframex.godot.ui.gdgui/
```

包同时发布在 GameFrameX npm registry，可被包管理工具直接消费：

```
https://npm.cnb.cool/GameFrameX/npm/-/packages/
```
