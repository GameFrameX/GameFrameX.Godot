## Overview

GameFrameX Setting — Godot persistent game settings package. Provides typed key-value storage (bool, int, float, string, serializable objects) with pluggable storage backends (defaulting to Godot PlayerPrefs), supporting load/save lifecycle, existence checks, and bulk removal.

## Quick Start

### Installation

Copy the package into your Godot project's `addons/` directory:

```
addons/com.gameframex.godot.setting/
```

The package is also published to the GameFrameX npm registry, so package-management tooling can consume it directly:

```
https://npm.cnb.cool/GameFrameX/npm/-/packages/
```

### Dependencies

- [`com.gameframex.godot`](https://github.com/GameFrameX/com.gameframex.godot)
