## Overview

GameFrameX Web — Godot HTTP request management package. Provides async GET and POST operations with string or byte array responses, support for query strings, custom headers, form data, and raw byte payloads, plus base/global request configuration (auto-appended headers, query params, form data) and configurable timeout.

## Quick Start

### Installation

Copy the package into your Godot project's `addons/` directory:

```
addons/com.gameframex.godot.web/
```

The package is also published to the GameFrameX npm registry, so package-management tooling can consume it directly:

```
https://npm.cnb.cool/GameFrameX/npm/-/packages/
```

### Dependencies

- [`com.gameframex.godot`](https://github.com/GameFrameX/com.gameframex.godot)
