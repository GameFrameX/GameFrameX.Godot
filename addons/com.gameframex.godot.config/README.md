## Overview

GameFrameX Config — Godot configuration and data table management package. Provides named configuration management with generic data tables (IDataTable<T>), supporting lookup by int/long/string IDs, LINQ-style queries (Find, FindList, ForEach, Max, Min, Sum), and async data table loading for non-blocking initialization.

## Quick Start

### Installation

Copy the package into your Godot project's `addons/` directory:

```
addons/com.gameframex.godot.config/
```

The package is also published to the GameFrameX npm registry, so package-management tooling can consume it directly:

```
https://npm.cnb.cool/GameFrameX/npm/-/packages/
```
