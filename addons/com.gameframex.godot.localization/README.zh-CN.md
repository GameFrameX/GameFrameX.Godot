## 简介

GameFrameX Localization — Godot 多语言本地化功能包。提供基于字典的字符串翻译，支持参数化格式化（最多 16 个类型化参数），运行时语言切换与事件通知，自动回退到系统或默认语言，并通过 Setting 系统持久化语言偏好。文档：https://gameframex.doc.alianblank.com

## 快速开始

### 安装

将包复制到 Godot 项目的 `addons/` 目录：

```
addons/com.gameframex.godot.localization/
```

包同时发布在 GameFrameX npm registry，可被包管理工具直接消费：

```
https://npm.cnb.cool/GameFrameX/npm/-/packages/
```
