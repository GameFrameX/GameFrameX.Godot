## 简介

GameFrameX UI FairyGUI — GameFrameX UI 系统的 FairyGUI 适配器。提供 FairyGUI 原生窗体实例化（UIPackage.CreateObject）、基于 GComponent 的 UI 分组与 GRoot 集成、FairyGUI 资源的正确释放，以及 FairyGUI 包的异步资源加载。文档：https://gameframex.doc.alianblank.com

## 快速开始

### 安装

将包复制到 Godot 项目的 `addons/` 目录：

```
addons/com.gameframex.godot.ui.fairygui/
```

包同时发布在 GameFrameX npm registry，可被包管理工具直接消费：

```
https://npm.cnb.cool/GameFrameX/npm/-/packages/
```
